# ColaLink - Encurtador de URLs

*ColaLink* é uma aplicação para encurtar e gerenciar URLs, permitindo criar links curtos e rastreáveis com facilidade.
---

## Visão Geral

ColaLink é um sistema de encurtamento de URLs com as seguintes funcionalidades:

- ✅ Criar links curtos a partir de URLs longas
- ✅ Gerenciar e registrar histórico de links
- ✅ Gerador de códigos curtos único e aleatório
- ✅ Agendamento de limpeza de links expirados

## Tecnologias Utilizadas

### Backend
- **Java 21** - Linguagem principal
- **Spring Boot 3.5.10** - Framework web
- **PostgreSQL 15** - Banco de dados
- **Flyway** - Versionamento de schema
- **Lombok** - Redução de boilerplate
- **SpringDoc OpenAPI** - Documentação automática da API

### Frontend
- **React 19** - Biblioteca UI
- **TypeScript 5.9** - Tipagem estática
- **TailwindCSS 4** - Styling
- **Axios** - Cliente HTTP

### DevOps
- **Docker** - Containerização
